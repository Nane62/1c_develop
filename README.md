#  **1с разработка**

## **Название проекта** 
«КофеИКод: учебная конфигурация 1С для автоматизации кофейни»

## **Цель проекта**
Разработка с нуля информационной базы на платформе 1С:Предприятие 8.3 в рамках учебного проекта. Конфигурация реализует базовый учёт продаж, поступлений и остатков товаров, а также формирование управленческих отчётов.

## **Основные функциональные блоки**
Справочники номенклатуры, клиентов и сотрудников; документы «Поступление товаров» и «Заказ клиента»; регистры накопления для учёта остатков; отчёты по выручке и популярным позициям.

## **Ожидаемый результат**
Рабочая учебная конфигурация с корректной логикой проведения документов, контролем отрицательных остатков и отчётами на СКД.
